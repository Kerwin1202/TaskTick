# 运行前参数

在任务编辑器的「命令」页开启「运行前询问参数」。一个任务可以配置多个参数，每个参数包含显示名称、环境变量名和输入方式。

任务编辑器共有三个页签，使用一致的窗口宽高，每页左右两栏分别滚动：

- **基本与调度**：左侧填写任务名称、启用状态和快捷键；右侧设置触发方式、时间和重复规则。
- **命令**：左侧设置 Shell、工作目录、前置命令和超时；右侧编辑脚本及运行前参数。
- **通知与推送**：左侧设置系统通知和强提醒；右侧设置远程推送和推送内容。

- **固定选项**：填写选项名称和实际值，选择默认项。选项按保存的顺序显示。
- **文本输入**：填写默认值，运行时可以修改。例如版本号、自定义 URL。
- **自动运行**：开启时默认等待 5 秒；可以调整为 1–300 秒，也可以关闭。切换选项或修改输入后取消倒计时，等待确认。移动窗口、点击空白处、查看当前选项和 Tab 切换焦点不会取消倒计时。
- **取消倒计时**：保留弹窗和当前参数，停止自动执行，方便核对内容；确认后点击「立即运行」。
- **取消执行**：关闭弹窗，放弃本次运行，不产生执行记录。
- **预览参数**：在保存前查看弹窗和选择结果，不执行实际命令。

主窗口、菜单栏、快捷启动和任务快捷键的手动运行使用同一套弹窗。只有一个单选参数时，可用上下键或数字 1–9 切换；回车确认、Esc 取消。输入法候选状态下的按键先交给输入法。

重启会先确认参数，再停止原进程；取消弹窗时原进程继续运行。定时、启动时执行以及普通命令行触发直接使用默认值。等待选择不计入执行时长、超时和执行次数。取消选择不创建新的执行记录。

选择结果只作用于本次进程，不会改写任务默认值。执行日志的「本次运行参数」和导出的日志会记录参数名称、所选选项和传入值。任务复制、导入导出和数据库备份也会保留参数配置。

## 在命令中使用变量

选中的值已经通过环境变量传给进程，无需再 `export`。例如变量名为 `VERSION`：

```sh
echo "$VERSION"                     # 显示版本值
./scripts/package-local.sh "$VERSION" # 把版本值作为参数
```

`"${VERSION}"` 与 `"$VERSION"` 都可以展开变量。单引号 `'$VERSION'` 会得到原样文字；`cat "$VERSION"` 会尝试读取名称等于版本值的文件，并不会显示版本号。

自定义脚本上方有「插入变量」菜单，每个参数的变量名旁也有插入按钮。先把脚本光标放到需要的位置，再选变量；插入的是带双引号的 `"${VERSION}"`，有选区时替换选区。放大的脚本编辑器也支持这个菜单。本地文件和模板模式可按说明在脚本中手动引用变量。

## CyberPai：选择服务环境

任务设为「仅手动触发」，工作目录：

```text
/Users/kerwin/Projects/stocks/StockTrading-Main/cyberpai
```

命令：

```sh
./start-app.sh
```

参数显示名称「服务环境」，环境变量名 `CYBERPAI_PLATFORM_SERVICE_URL`，输入方式「固定选项」：

| 选项名称 | 传入值 |
| --- | --- |
| 本地服务 | `http://127.0.0.1:8100` |
| 远程服务 | `http://8.133.247.14:8100` |

把「本地服务」设为默认项，按需开启 5 秒自动运行。脚本应读取这个变量；命令中显式写死 URL 会覆盖选中的值。

## OneTool：选择固定设备

工作目录 `/Users/kerwin/Projects/OneTool`。设置一个固定选项参数，变量名 `ONETOOL_DEVICE_UDID`；选项名称填写设备名称，传入值填写完整 UDID。

```sh
bash ./Scripts/install-device.sh "$ONETOOL_DEVICE_UDID"
```

传入 UDID 后安装脚本可以直接执行，不需要终端选择界面。目前选项由用户配置；自动发现设备的动态列表属于后续功能。

## TaskTick：输入打包版本号

工作目录 `/Users/kerwin/Projects/Forks/TaskTick`。参数显示名称「版本号」，变量名 `TASKTICK_VERSION`，输入方式「文本输入」，默认值例如 `1.26.0`。

```sh
bash ./scripts/package-local.sh "$TASKTICK_VERSION"
```

传入版本号后，打包脚本会使用该值。可以关闭倒计时，填写完再手动确认。长时间的编译、服务或安装任务可以保持执行超时关闭。
